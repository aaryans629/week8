# Week 8 Java Solutions (Polymorphism & Inheritance)

This repository contains clean, modular Java implementations for Week 8 problems, organized by dedicated Git branches:

- **`assignment` branch**: Contains 5 Assignment problems (Canteen Billing, Campus Parking, Hostel Electricity Bill, Festival Bonus Calculator, Streaming Plan Renewal) and documentation.
- **`practice` branch**: Contains 5 Practice problems (Payment System Fee, Library Item Due Date, Delivery Fee Calculator, Exam Question Grader, Public Transport Fare) and documentation.
